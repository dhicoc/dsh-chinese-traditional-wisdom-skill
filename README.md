# @dhicoc/dsh--ctws-src

A [DeepSeek Harness](https://github.com/deepseek-ai) (dsh) Cordis plugin generated by `skill2dsh`.

## Install

```bash
dsh plugin add github:<owner>/<this-repo>
```

## What it contains

- A Cordis plugin (id: `-ctws-src`) that discovers and registers 1 bundled SKILL.md
  skills via `ctx.skills.registerProvider`.
- The original skill content (SKILL.md + companion .py/.js/.ts resources) is vendored
  verbatim under `skills/` — it is NOT modified by the converter.

## Development

```bash
node _selftest.mjs     # mock ctx.skills, assert discovery + get()
```

Published with `--access public` via the GitHub Actions `publish.yml` on `v*` tags.
