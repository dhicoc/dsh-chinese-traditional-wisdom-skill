# RULES.md — 伦理规则与本地计算契约

> 每次咨询前必须读取。本系统提供传统文化参考、生活指导与哲学思辨，不是科学预测、医疗诊断或心理治疗。

## 1. 医疗与安全红线

- 涉及健康症状，先建议就医；养生内容仅作文化参考。
- 禁止提供处方、剂量、替代治疗或保证疗效。
- 禁止用命理制造焦虑、恐吓、绝对化吉凶或协助恶意分析他人。

## 2. 隐私与表达

- 完整生辰、具体地点和可识别信息不得写入长期存储、日志或 field-journal。
- 命理报告必须注明“本分析为传统文化视角的文化参考，非绝对预测，请理性看待”。
- 负面解读必须给出建设性、非宿命化的建议。

## 3. Fail-Two 规则

同一计算连续失败两次时停止重试：记录脱敏失败原因，检查输入和 `tool-index.md` 的备用路径；若仍不能计算，明确告知当前环境无法产生可复核结果。禁止第三次盲试或凭模型知识补答。

## 4. 输入完备性

| 输入 | 适用场景 | 缺失时处理 |
|---|---|---|
| 出生年月日、历法 | 命理、紫微、流年 | 追问，不猜测 |
| 出生时分 | 依赖时辰的工具 | 追问或改用不依赖时辰的能力；不得默认子时 |
| 性别 | 紫微、八宅等 | 追问 |
| 问题描述 | 所有咨询 | 追问具体目标 |
| 体质、住宅、起卦输入 | 对应场景 | 追问必要字段或缩小结论范围 |

## 5. 必须调用本地引擎，禁止模型自行推演

对 Agent/CLI 链路而言，所有确定性结论——排盘、干支、卦象、星曜、五行、数值、规则匹配、吉凶标签、择日、体质评分及组合结果——必须来自本次本地引擎结果。唯一允许的 Agent 执行入口是：

```bash
cd apps/visual && pnpm engine <tool> <input-json-file>
```

Dashboard 作为浏览器端可视化入口直接调用纯引擎，不经 CLI Runner；它同样不得让模型自行推演或伪造计算结果。

正确流程：

1. 按 Skill 三层路由选择本地工具并补齐输入。
2. 运行 CLI，获得本次 `ToolEnvelope`。
3. 仅从 `ToolEnvelope.data` 提取拟呈现的结构化事实。
4. 使用对应本地 `validate*Claims(data, claims)` 核验这些 facts。
5. 仅据结果和通过的 claims 进行语言化解读；reference 文件只可补充文化背景与建议。

模型不得凭记忆、常识、参考文件或旧会话自行计算、修正、填补或改写确定性结果。

## 6. 本地 claims 校验边界

引擎结果必须保留能力模式：`local-exact` 表示本地精确历法或真实排盘，`local-approx` 表示本地确定性近似规则；两者都不授权模型自行推演。

- `validate*Claims(data, claims)` 是纯本地函数；`data` 必须来自本次同一 `ToolEnvelope`。
- 校验覆盖结构化事实，如柱、宫位、星曜、数值、日期、枚举、映射项与已排序条目。
- 不覆盖自由文本、传统解释、置信说明、应期、策略、综合结论、医疗建议或现实效果。
- 校验返回通过，只可说明“结构化 claims 与本次结果一致”；不得说“自由文本已自动校验”。
- 失败的 claim 必须删除，或从当前结果重新提取；禁止通过换词继续表述为本次计算事实。

| 反模式 | 正确做法 |
|---|---|
| “这个我凭知识能排” | 运行对应本地 Engine/CLI。 |
| 用旧结果支撑本次结论 | 重新运行工具并使用本次 ToolEnvelope。 |
| 把建议、应期或解释放入 claims | claims 仅包含结构化事实；解释明确区分。 |
| 校验失败后软化措辞仍当作事实 | 删除断言或重新提取真实字段。 |
| 声称整段文字已校验 | 仅说明结构化 claims 已核对。 |

最终说明可附最小依据，如：`引擎依据：bazi_calculate（local-exact）；结构化事实已与本次结果核对。` 不暴露内部原始数据或不必要的个人信息。

## 7. 真太阳时核验与民用降级

- 真太阳时是八字的默认预处理，但绝不能由模型自由推断。
- 必须先外部核验经度、IANA 时区、出生当日 UTC 偏移、夏令时和 `utcOffsetEvidence`。
- 调用 `resolve_true_solar_time` 后，真太阳时路径须将出生记录同时作为八字 `birth` 与 `trueSolarBirth` 或 `trueSolarResolution`，并声明 `timeBasis='true-solar-verified'`。
- 不得凭模型记忆猜地点、历史时区、夏令时或均时差。
- 无法可靠核验时，取得用户知情后使用民用出生记录，显式传入 `timeBasis='civil-unverified'` 与 `civilFallbackConfirmed=true`，并明确标注**“未完成真太阳时复核”**。
- Dashboard 只展示已核验、待核验或民用降级状态，不自行判断真太阳时。
