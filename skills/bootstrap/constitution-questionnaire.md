# 体质辨识问卷

> 本问卷用于传统中医体质的自我观察，不能替代医师诊断。涉及症状时请先就医。

## 本地直调

```bash
cd apps/visual && pnpm engine list_constitution_questionnaire <input-json-file>
cd apps/visual && pnpm engine assess_constitution <input-json-file>
```

先取题目，再将用户的结构化答题结果交给评分工具。输出为 `ToolEnvelope`；主体质与转化分等结构化结果可用本地 `validateDailyClaims('assess_constitution', data, claims)` 核对。调养解释、生活建议和医疗安全性不属于 claims。

## 使用方法

1. 逐一询问题目，或请用户按 1–5 分自评：1=没有，5=总是。
2. 让本地评分工具计算各类型分数；不要由模型手算。
3. 用主体质和兼夹倾向做传统文化层面的日常建议。
4. 明确说明结果不等同诊断，不作处方或疗效承诺。

## 九种体质参考

| 体质 | 常见观察方向 |
|---|---|
| 气虚质 | 易疲乏、气短、自汗等主观感受 |
| 阳虚质 | 怕冷、手足凉、受凉不适等 |
| 阴虚质 | 口干、手足心热、干燥等 |
| 痰湿质 | 困重、痰多、油腻感等 |
| 湿热质 | 油腻、口苦、黏滞感等 |
| 血瘀质 | 瘀斑、面色晦暗等 |
| 气郁质 | 情绪低落、紧张、叹气等 |
| 特禀质 | 过敏相关表现等 |
| 平和质 | 精力、适应性和睡眠等整体状态 |

## 边界

- 单一症状不能确定体质；不少人为兼夹体质。
- 女性经期、孕期、年龄和环境变化可能影响自评。
- 饮食、穴位与生活建议仅供传统文化参考，具体健康问题请咨询合格医疗专业人员。
