# 神煞柱位检视设计

## 目标

将四柱主盘底部的神煞摘要升级为可完整查阅的柱位索引。盘面应明确每项神煞落在年、月、日、时哪一柱，同时不以截断名称或密集文字破坏四柱阅读。

## 范围

- 替换当前每柱“前两项神煞简称 +N”的展示。
- 在 SVG 内为命中神煞的柱显示朱砂计数印章。
- 用户点击印章后，在主盘下方显示该柱全部神煞明细。
- 保留左侧既有的全局神煞总览，不改变神煞推算规则、分类、数量或解释文案。

不在本次范围内：新增神煞规则、修改 `shensha.ts` 推算口径、跨柱筛选、弹窗或 tooltip。

## 信息架构

### 主盘索引层

每个命中至少一项神煞的柱，在藏干下方显示一个朱砂印章：`神煞 N`。`N` 是该柱 `ShenShaItem[]` 的长度。未命中神煞的柱不显示印章。

印章不显示神煞简称，避免长名称和多项目在窄列内发生重叠。日柱仍仅以现有金色高亮表达，不因神煞状态改变。

### 柱位明细层

主盘下方新增内联“柱位神煞”区。默认选择第一个有神煞的柱；用户点击任意柱的计数印章后，切换到对应柱。

明细区标题显示“年柱神煞”等柱位名称与总数。每项展示：

- 神煞全名
- 分类
- 触发地支
- `ShenShaItem.meaning` 的完整说明

明细按引擎返回顺序展示，保证与当前总览和既有推算结果一致。

## 组件与数据流

- `BaziWorkspace` 持有 `activeShenShaPillar` 状态，取值为 `年 | 月 | 日 | 时 | null`。
- `BaziWorkspace` 从 `result.shenSha` 按 `pillar` 过滤出活动柱明细，并在 `BaziPillarsChart` 下渲染内联明细组件。
- `BaziPillarsChart` 接收可选 `activeShenShaPillar` 与 `onSelectShenShaPillar`。只有神煞计数印章为可操作元素；通过 SVG 的 `role="button"`、键盘 Enter/Space 和 `aria-pressed` 提供可访问性。
- `BaziPillarsChart` 继续接受原有 `shenSha`，仅负责按柱计算数量并发出柱位选择事件，不复制神煞解释逻辑。

## 交互与响应式

- 点击计数印章立即切换明细，不使用模态框。
- 当前活动柱的印章使用更深朱砂底和边框，其他印章使用轻朱砂色。
- 键盘 Tab 可聚焦印章，Enter 或 Space 可选择。
- 窄屏下 SVG 可继续由既有 `ZoomableSvg` 和横向容器处理；明细区使用单列垂直列表，说明文本自然换行。
- 无神煞数据时不渲染印章和柱位明细区，避免空白占位。

## 验收标准

1. 每柱印章的计数与该柱全部 `ShenShaItem` 数量一致。
2. 选择年、月、日、时任一印章后，明细只显示该柱项目，且每项包含名称、分类、地支与含义。
3. 长名称（如“天乙贵人”“阴差阳错”）仅在明细区完整显示，SVG 内没有截断文字或相邻重叠。
4. 未命中神煞的柱不产生可点击印章。
5. SVG 印章支持鼠标与键盘操作，并提供活动状态语义。
6. 现有 TypeScript 检查、Dashboard smoke 测试与相关单元测试通过。
