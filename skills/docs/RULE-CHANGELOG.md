# 规则与引用变更记录

本记录用于追溯映射表、古籍引用 ID、确定性规则及其维护口径的变更。它不替代 Git 历史；每次变更都应说明来源、兼容性影响和已执行的回归证据，避免仅更新夹具掩盖规则漂移。

## 变更条目格式

- **日期**：变更完成日期。
- **范围**：受影响的映射表、古籍引用 ID、规则或公开契约。
- **来源**：原始文献、数据来源、上游依赖或已核验的维护决策。
- **兼容性影响**：对已有输入、输出、报告或引用的影响；无影响时明确说明。
- **回归证据**：对应 fixture、契约检查、单元测试、构建或浏览器测试。
